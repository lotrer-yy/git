# 追逐居中构图

幽灵和追兵各自使用脚底以外的 Focus 构图点。幽灵为身体中心，追兵为整团素材中心。提前推镜时一并下移取景中心，让幽灵出场后位于画面中部。跟拍和切换同时平滑处理横纵两个方向，Focus 不随弹跳晃动，因此镜头不会跟着每次跳动上下抖。

水平预判改为 96 像素，补偿 720 像素/秒速度下的跟拍滞后。镜头视野按当前缩放限制在地图内。地图底边附近优先保证不露底，幽灵稳定跟拍时接近画面中央。进场、甩镜途中和最终跑出画面仍保留既有动作。提前推近、奔跑速度、前景遮挡与 R 重播不变。

可在 Godot 中调整 Ghost/Focus、Mob/Focus 和 PreChaseZoom 的 focus_height。
