# 幽灵向前弹跑

每一步先短促压身，身体稍微收在后面，然后蹬出时向前拉伸、前倾并冲一下。保留低跳和超过半周期的地面接触。形变通过连续弹簧追踪，替换原来接地瞬间突变的缩放，减少生硬感。

forward_bounce.gd 只控制 Ghost/Visual。cinematic_runner.gd 继续负责路线与匀速推进，通过 animate_visual 开关允许独立表现模块接管。恶魔保留原来的动画，镜头跟踪点不跟随视觉前冲，避免每一步晃镜头。

Godot 中选中 Ghost/Visual 可调整 Forward Distance、Forward Lean Degrees、Stiffness、Damping；原来的奔跑速度、分镜时序和场景衔接不变。
