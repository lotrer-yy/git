# 追逐开场测试

首页 Start → 下潜 → 加载角色有序离场 → 幽灵进场与跟随 → 快速回看追兵 → 回到幽灵 → 定住镜头，让幽灵向右离开。R 在任何阶段回到首页，重新播放完整流程。画面不添加文字。

- `scenes/cinematics/opening_chase_actors.tscn`：角色素材、脚底轴心、起点与追兵构图，可在 Godot 中编辑。
- `modules/visual/cinematic_runner.gd`：匀速跑动与脚底弹跳；速度、频率、弹跳高度和压扁幅度可调。
- `modules/camera/cinematic_chase_camera.gd`：横向跟随、移动目标间平滑转向与地图边界。
- `modules/cinematic/opening_chase_director.gd`：分镜时序，三个时间参数在检查器中可调，结束发出 finished 信号。
- `scenes/ui/main_menu.gd`：只负责将加载 finished 信号连接到开场 start，以及 R 重载。

美术按透明范围裁切，保留原始颜色和构图，来源与哈希记录于 assets/art/cinematic/来源.json。追逐总画面只作比例参考，背景沿用开场地图。此版追兵采用整团弹跑，不包含后续战斗或附身。
