# 粗柱子衔接正式地图与小幽灵入场

新红柱子材质替换了最前景柱子的导入副本，保留虚化和视差。追逐结束后使用作者“游戏开场动画-游戏画面的衔接.png”中整段粗墙，从右向左扫过；完全遮挡期间切换到正式地图底部。露出地图时，白色小幽灵从左侧墙后弹出，落地后交还 WASD 控制，R 仍从首页完整重来。

## 模块

- modules/cinematic/pillar_game_handoff.gd：预加载地图、粗柱子遮挡与换镜头。
- modules/cinematic/soul_wall_entry.gd：可调起点、落地点、弹出时长和弧高，落地后启用原有移动模块。
- scenes/levels/formal_hell_entry.tscn：组装正式地图、原来的 soul.tscn、跟随镜头和初始地面/左右墙碰撞。碰撞与入场 Marker2D 均可在编辑器调整。
- scenes/map/formal_world_map.tscn 与 assets/formal_map：复用正式地图工程已有的分块地图和预览，独立路径；原正式地图项目未修改。
- modules/map：正式地图原有的高清切片加载和有限范围视差模块。

当前衔接只接入小幽灵和初始地面移动，没有新增恶魔、叉子、敌人或其他尚未布置的关卡内容。角色使用原来的白色小幽灵，而非追逐用的表情素材；墙的前景层始终在角色上方。
