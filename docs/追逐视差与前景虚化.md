# 追逐视差与前景虚化

三个独立景深层：远背景运动倍率 0.65，中前景 1.0，最近柱子 1.3。镜头向右跟跑时，远处移动慢，柱子更快从眼前掠过。两者横向错位，纵向保持原始位置。背景使用用户新提供的纯背景板，消除旧合成地图中重复岩壁的问题。

- `modules/environment/cinematic_parallax_layer.gd`：独立视差模块，按镜头坐标计算，不累积偏移。
- `shaders/foreground_soft_blur.gdshader`：只柔化柱子自身，不读取或模糊整屏。透明像素预乘加权，避免素材透明区的白色污染边缘。
- `scenes/ui/opening_cinematic_map.tscn`：FarBackground（背景）、ChaseActors（角色，2）、Foreground（中前景，10）、NearPillars（最近柱子，20）。

Godot 检查器中可调整两层的 motion_scale、柱子的位置，以及 PillarBlur 材质的 blur_radius（默认 8，设 0 恢复清晰）。四根柱子复用用户同一张素材，原图未修改；导入裁切与透明边距记录于来源.json。

原来的居中跟拍、提前推镜、奔跑速度和 R 重播保持原样。
