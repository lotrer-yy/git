# 背景音乐

`Bgm` 自动加载模块负责循环播放，以及先淡出旧曲、再淡入新曲。淡出、淡入默认各 1.5 秒，正常音量为 0 dB，可调整 `bgm.gd` 的导出参数。

| 文件 | 使用位置 |
| --- | --- |
| 01升天.mp3 | 首页与下潜动画 |
| 02地狱1.mp3 | 下潜结束后的开场追逐及地狱 |
| 03海底1.mp3 | 海底 |
| 04丛林1.mp3 | 丛林 |
| 05天空.mp3 | 天空 |
| 06天堂.mp3 | 天堂 |

音乐素材位于 `assets/audio/bgm/`。首页通过 `ArrivalMotion.arrived` 信号切换到地狱曲，后台预载不会提前切歌。重回首页会切回第一首。

正式地图使用 `map_bgm.gd` 按相机在地图中的局部高度选曲，区域边界在该模块的导出参数中调整。首页交接完成前禁用区域选曲；独立运行正式地图或地图浏览器时自动启用。正式地图尚未实现上方关卡的角色流程，可在“正式地图工程”的 `scenes/map_browser.tscn` 中滚动浏览并试听各区音乐。

旧原型 `scenes/game_flow.tscn` 使用海底抵达、上岸、树冠抵达、天堂抵达与重开信号切歌。相同曲目不会重新开始，连续切换时以最后一次请求为准。

根目录与“正式地图工程”保持相同的音频模块和素材，各工程独立运行，不依赖本机 `D:/YU/BMG/` 路径。

首页音乐保持 1 倍速。第二首地狱 BGM 从实际开始播放时计时，前 10 秒以 1.2 倍速播放，第 10～11 秒线性降至 1.1 倍速，之后保持 1.1 倍速；计时包含淡入，不随音频循环重新开始。通过独立的 `BgmMusic` 总线同步进行倒数音高补偿，保持原调，不影响其他音效。切到其他曲目时恢复 1 倍速，再次从头播放地狱曲时重新计时。
