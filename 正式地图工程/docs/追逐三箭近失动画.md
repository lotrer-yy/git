# 追逐箭雨模块

先展示幽灵出场和恶魔群追逐，镜头回到幽灵后通过 ghost_returned 启动 NearMissArrows（延迟 0.65 秒等待甩镜收稳），直至幽灵完全进墙后停止。持续射击的间隔、短连射、飞行速度、抛物线高度和脚后落点均有变化，避免固定三连发节拍。脚后间距至少 155 像素，全部视觉箭，无角色碰撞与伤害。

PillarArrows 保留前景柱子的两个中箭点。箭落定后成为落点子节点，跟随柱子视差移动。

幽灵完全进入最后墙后，finished 启动 ExitArrows。24 支箭以 0.012～0.035 秒的非均匀间隔射向 FinalSideWall 下的 WallImpact 标记，落点分散在墙面，飞行时间略有不同。箭层级 61，落定后挂到墙上，层级为墙 60 + 箭 1。保留原墙后停顿和连续右移进游戏的时机。

- near_miss_volley.gd：持续追射的节奏与角色脚后安全落点。
- surface_arrow_volley.gd：场景落点射击，支持随机间隔、飞行时差。
- near_miss_arrow.gd：曲线飞行、沿切线转向、落地轻颤、钉住表面、清理。
- opening_cinematic_map.tscn：组装三组箭及可拖动的柱子、墙面落点。

R 重载清空全部箭。背景、运镜与正式关卡连续拼接保持不变。学习参考：[ProjectileOnCurve2D](https://github.com/MeroVinggen/Godot-ProjectileOnCurve2DPlugin)，没有安装或依赖第三方插件。
