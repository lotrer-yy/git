# 动画和正式关卡是同一个连续世界

动画通道在左，正式地图在右。作者新版大柱子的右沿与正式地图左墙外沿都是 RGBA(106,34,34,255)。两者按实际纹理宽度和节点变换计算接缝，直接贴边，不相互重叠，也不额外叠另一张墙。

正式地图在追逐期间后台加载，高清准备好后就驻留在右侧。追逐镜头的右边界恰好到接缝，最后右移前只看到动画和柱子；不靠显示开关隐藏地图。幽灵进墙后，恶魔在左侧画外停止。短暂停顿后，同一台显示相机平移到右边，沿途自然露出正式关卡。平移结束后，原白色小幽灵从这堵墙另一侧弹出、落地，交还 WASD。R 从首页重播。

没有切场景、切换显示相机、扫屏、淡入淡出或最后一帧突然显示地图。墙与地图始终在相同世界坐标系中。

- modules/cinematic/pillar_game_handoff.gd：后台预载、精确贴边组装、停顿、最后右移。
- modules/camera/follow_camera_output.gd：把游戏跟随计算结果交给原来的显示相机，不更换相机。
- modules/cinematic/soul_wall_entry.gd：原小幽灵从墙另一侧弹出与落地。
- modules/map/map_texture_streamer.gd：附近高清切片预加载与就绪检查。
- scenes/ui/opening_cinematic_map.tscn：动画末端 FinalSideWall。
- scenes/levels/formal_hell_entry.tscn：正式地图、原白幽灵、初始碰撞与可编辑起落点。

原正式地图工程未修改；当前工程引用此前复用到 assets/formal_map 的地图资产。没有新增敌人、附身或其他关卡内容。
