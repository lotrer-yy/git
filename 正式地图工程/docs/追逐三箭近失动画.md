# 追逐三箭近失动画

GitHub 学习参考：[ProjectileOnCurve2D](https://github.com/MeroVinggen/Godot-ProjectileOnCurve2DPlugin)。该 Godot 4 插件支持曲线飞行与沿切线转向。本项目参考此思路，针对固定三箭分镜编写轻量模块，没有安装或依赖第三方插件。

镜头回到幽灵后 0.55 秒开始，间隔 0.28 秒射出三支作者绘制的箭。箭从恶魔方向的画面左侧飞入，瞄向预计位置后方 170、145、122 像素，依次更接近脚后方。每支箭发射后路径固定，不追踪小幽灵。箭尖落在脚后地面，轻颤后随镜头离开；不添加文字、碰撞或伤害。

- modules/cinematic/near_miss_volley.gd：三个发射时机和安全落点。
- modules/cinematic/near_miss_arrow.gd：单支箭的弧线、方向、落地轻颤和清理。
- scenes/cinematics/near_miss_volley.tscn、near_miss_arrow.tscn：独立场景与可调参数。
- OpeningChase 通过 ghost_returned 信号触发，与镜头模块解耦。

箭层级为 6，位于中前景岩石、柱子和最后墙体之后；R 重载时一起清理。前冲弹跑、背景视差和正式关卡的连续拼接保持原样。


## 柱子中箭与出口追加箭雨

保留原三箭。最后回到幽灵时，另有两支箭依次射中第三根前景柱子的 ArrowImpact1/2。落点可在编辑器拖动；箭落定后成为落点的子节点，随柱子视差移动，层级 21，与柱子共同构成前景遮挡。

镜头停止跟跑、幽灵向右离场时，通过 ghost_exiting 信号射出九支出口箭，间隔 0.055 秒，落在墙前的九个 ExitImpact 标记。层级 6，受前景岩石与最后墙体遮挡；不改变原有停顿、右移、加载和进游戏时机。

surface_arrow_volley.gd 只负责场景落点射击，near_miss_arrow.gd 复用飞行、钉住和清理。两组独立节点 PillarArrows / ExitArrows，参数可在 Godot 编辑器调整。所有箭均为视觉表现，不带伤害或角色碰撞，R 重载同时清空。
