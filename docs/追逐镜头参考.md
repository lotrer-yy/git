# 追逐镜头参考与下一步方案

本次先修复中前景遮挡，未安装插件，未改变已保存的追逐节奏。

## GitHub 资料

- Camera Systems：https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/camera-systems/SKILL.md 。适合研究预判构图、平滑跟随、考虑缩放的地图边界。
- Game Feel：https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/game-feel/SKILL.md 。适合研究短促反馈、缓动和挤压拉伸，抖动应有明确触发事件。
- Phantom Camera：https://github.com/ramokz/phantom-camera 。Godot 4 插件，不是 skill；支持目标跟随、镜头优先级切换、2D 缩放和镜头转场。

## 当前判断与建议（尚未实施）

角色速度固定为 460 像素/秒，开头跟随 4.8 秒，缺少迫近和加速的变化。建议先缩短铺垫；追兵镜头用更紧的构图，快速回看后留出短暂辨认时间；回到幽灵时让它短暂落在画面边缘，再追上并稳定构图，最后收镜放它出画。避免全程高频抖动。

中前景与地图坐标严格一致，层级为背景 0、角色 2、中前景 10。它包含原图中的上下岩壁，不能直接随意提高移动速度，否则会与背景里重复的轮廓错开。若要明显的前景视差，需先获得去掉这些岩壁的纯背景，或单独提供更近处的装饰素材。
