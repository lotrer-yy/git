## 组装与复用

- 地面移动：CharacterBody2D 下建立 Input、Movement 节点，分别挂 input/platformer_input.gd、movement/platformer_motor.gd，另外设置角色碰撞体。
- 水下移动：参考 res://scenes/actors/fish.tscn 的水下输入、移动、AI、视觉与附身组合。
- 飞行移动：参考 res://scenes/actors/bird.tscn 的扇翅输入、移动、AI、视觉与附身组合。
- 通用弹动：在 Node2D 或 Control 下添加 Node，挂 visual/elastic_pulse.gd。Interval 大于 0 时周期弹动；为 0 时可调用 pulse() 触发。
- 镜头跟随：在 Camera2D 上挂 camera/follow_camera.gd，设置 Target Path 和地图边界。
- 鼠标眼神：参考 res://scenes/ui/main_menu.tscn 的 God 节点；Eyes、Brows 是独立子节点，父节点挂 visual/mouse_gaze.gd。

现成角色组合保存在 res://scenes/actors/，首页组合保存在 res://scenes/ui/main_menu.tscn。

## 依赖说明

独立保存不代表每个脚本都能单文件运行。部分模块依赖 Input、Movement、Visual 等节点名，或 PlatformerInput、FollowCamera、PossessableHost 等脚本类型。复制到新项目时要包含相关依赖，以及实际需要的素材和材质，并保留或修正资源路径。

physics/verlet_rope_2d.gd 是 RefCounted 求解器，由藤蔓模块调用，不直接挂在节点上。场景出口、憋气及上岸等模块带有本游戏的流程约定，跨项目时需要适配。


## 开场到正式地图

- `cinematic/pillar_game_handoff.gd`：正式地图后台预加载、进墙后停顿、连续向右平移和镜头交接。
- `cinematic/soul_wall_entry.gd`：原小幽灵从墙后弹出的弧线，落地后交还操作。
- `map/map_texture_streamer.gd`：正式长地图附近高清切片的后台加载与释放。
- `map/finite_parallax.gd`：四区背景有限范围视差。
- 组装场景：`scenes/levels/formal_hell_entry.tscn`，起点、落地点、地面和左右墙碰撞可在 Godot 中调整。

- `camera/follow_camera_output.gd`：继续使用开场的同一台显示相机，承接正式关卡跟拍。

## 小恶魔死亡弹起

`environment/hell_demon_death.gd` 使用作者的死亡原图播放短压扁、向上弹起和加速下落。只移动视觉替身，机关、碰撞体与镜头冻结；结束后显示死亡界面，重来清理替身。可调参数：`jump_speed`、`fall_gravity`、`squash_seconds`。

## 死亡瞬间轻震

`camera/death_impact_shake.gd` 在死亡冻结期间播放真实时间 0.20 秒的相机偏移，默认强度 18 像素，以纵向为主避免窄地图横向边界抵消反馈，坠出地图用 35% 力度；不改相机中心、缩放或角色碰撞。结束与重来均归零。`DeathFlow/ImpactShake` 的 `strength_pixels` 设为 0 可关闭，`duration` 调整时长。

团团 `environment/hell_target.gd` 在首次进入选中状态时压扁回弹一次，0.32 秒内回到原大小；取消选中、命中和重来会取消旧动画。美术围绕原球心变化，碰撞、锁定范围和传送点不变。可调 `selection_pop_scale`、`selection_pop_seconds`。
