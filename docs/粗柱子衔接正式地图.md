# 幽灵进墙、停顿与连续右移

追逐动画提供正式地图后台加载时间。追逐开始时预载地图底部的高清切片；地图摆在通道右侧，在追逐、停顿和最后一次右移的全过程保持隐藏。

幽灵跑进最后的厚墙后消失，恶魔在左侧画外停止，不进入停顿镜头。停 0.65 秒后，只有附近高清切片已准备好才开始向右平移。平移用原相机，保持高度与缩放不变，不使用柱子扫屏、黑屏或场景瞬切。只有最后一次右移完全结束，才显示正式地图，并开始原白色小幽灵从墙后弹出的动画；落地后交还 WASD 操作。相机交给游戏跟拍时，接收完全相同的位置和缩放，避免抽帧。

- `modules/cinematic/pillar_game_handoff.gd`：后台预载、停顿、连续平移和镜头交接。
- `modules/cinematic/soul_wall_entry.gd`：侧墙弹出、落地及操作交还。
- `modules/map/map_texture_streamer.gd`：高清切片后台加载与就绪检查。
- `modules/camera/follow_camera.gd`：adopt_view 接收已有视野，之后恢复平滑跟拍。
- `scenes/ui/opening_cinematic_map.tscn`：最后厚墙是固定世界节点 FinalSideWall，挡住角色；按新版原图 x=5440 的位置摆放，不再沿用旧版大柱子的坐标；最近第四根细柱由此替代。
- `scenes/levels/formal_hell_entry.tscn`：正式地图、小幽灵、初始地面/左右墙碰撞及可编辑起落点。

原正式地图工程未修改；当前工程通过 assets/formal_map 与独立地图场景复用已有资产。R 随时从首页重播。没有新增敌人、附身或其他关卡内容。

时序门槛：`gameplay.visible` 与 `WallEntry.play()` 只在 `_pan_elapsed == pan_duration` 后触发，不能在平移开始或途中触发。
